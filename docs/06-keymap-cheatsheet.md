## 窗口

| 键 | 动作 |
|---|---|
| ★ `Ctrl+Alt+H/J/K/L` | 焦点 左/下/上/右（**全屏下也保持方向感**；焦点在 group 里时优先切组内标签） |
| ★ `Ctrl+Alt+Shift+H/J/K/L` | 把窗口搬向该方向 |
| ★ `Alt+G` | 建组/拆组（组内窗口再按一下会**整组解散**，不是只踢走当前这个） |
| ★ `Ctrl+Alt+Shift+G` | 把当前工作区的窗口一键收进一组 |
| ★ `Alt+Enter` | 真全屏（盖住顶栏） |
| ★ `Alt+Shift+Enter` | 最大化（保留顶栏） |
| ★ `Alt+W` | 关闭窗口 |
| `Super+F` / `Super+D` | 全屏 / 最大化（官方备用入口） |
| `Super+Q` | 关闭窗口 |
| `Super+Escape` | 强杀窗口（`hyprctl kill`） |
| `Alt+Tab` | 循环切窗口 |
| `Super+Tab` | noctalia 窗口切换器 |
| `Super+Alt+Space` | 切换浮动/平铺 |
| `Super+J` | 翻转分割方向 |
| `Super+左键拖` / `Super+右键拖` | 移动 / 缩放窗口 |
| `Super+Shift+←/→/↑/↓` | 把窗口搬向该方向 |
| `Super+Shift+1/2/3` | 把窗口丢到 1/2/3 号显示器 |

## 桌面（纯动态工作区）

> ★ 标记的这几个键是**模态**的：在抽屉架里含义会变（见下一节）。

| 键 | 动作 |
|---|---|
| ★ `Alt+[` / `Alt+]` | 上/下一个桌面 |
| ★ `Ctrl+2` / `Ctrl+3` | 同上，**纯左手版** |
| ★ `Ctrl+1` / `Ctrl+4` | 直接跳到**第一个 / 最后一个**桌面（同一只左手，1234 连成一组） |
| ★ `Alt+Shift+[` / `]` | 带着当前窗口跳过去 |
| ★ `Alt+T` | 在**最右边**新建一个桌面 |
| ★ `Alt+Shift+T` | 带着当前窗口去新桌面 |
| ★ `Super+Ctrl+1..9` | 跳到本显示器第 N 个**已存在**的桌面（按位置，不是编号） |
| ★ `Super+Shift+Ctrl+1..9` | 把窗口丢到第 N 个 |
| `Super+Ctrl+←/→` | 上/下一个桌面 |
| `Super+Ctrl+↓` | 跳到第一个空桌面 |
| `Super+滚轮` | 滚动切桌面 |
| `Super+1/2/3` | 焦点切到 1/2/3 号显示器 |

> 没有「删除桌面」这个动作——把一个桌面搬空，它自己就消失了。

## 抽屉架 —— 第二套工作平面

`Alt+S` 切换的不是「一个抽屉」，是**整个平面**：底下是工作桌面（正事），上面是抽屉架
（聊天、媒体、下载器），抽屉架自己也能有多格。满屏显示，收起来自动回到原来那个工作桌面。

**同一批键，两个平面两套含义**（零新增键位）：

| 键 | 工作平面 | 抽屉架里 |
|---|---|---|
| `Alt+S` | 进抽屉架（回上次那格） | 收起，回工作平面 |
| `Alt+[` `]` · `Ctrl+2` `3` | 上/下一个桌面 | 上/下一格抽屉（**回绕**） |
| `Ctrl+1` `Ctrl+4` | 第一个/最后一个桌面 | 第一格/最后一格 |
| `Alt+T` | 新建桌面 | 新建一格抽屉 |
| `Alt+Shift+[` `]` | 带窗口切桌面 | 带窗口切抽屉格 |
| `Alt+Shift+T` | 带窗口去新桌面 | 带窗口去新抽屉格 |
| `Alt+Shift+S` | 把当前窗口**藏进**抽屉架 | 把窗口**捞回**工作桌面 |

- `Alt+Shift+S` 藏窗口时**不弹出**抽屉架，窗口原地消失。想改回「跟着窗口一起过去」，
  把 `mykeys.lua` 顶部的 `STASH_SILENTLY` 置 `false`。
- 捞出来的窗口落在**当前**工作桌面，不是它原来那个。
- `Alt+S` 也是老板键 —— 一下回到干净的工作桌面。
- 抽屉格搬空会自动消失。所以 `Alt+T` 新开一格却不放东西就离开，那格会当场蒸发
  （和「空桌面不赖着」是同一个规则）。

## 截图 / 录屏 / 取字 / 取色

修饰键分工：**`Shift` = 框选，`Alt` = 整屏**，截图（`P`）、录屏（`R`）、取字（`O`）三套一致。

| 键 | 动作 |
|---|---|
| `Print` | 区域截图 → 落盘 `~/Pictures` + 管道进 satty |
| `Super+Print` | 全屏截图 → 同上 |
| `Super+Shift+P` | 区域截图（同 `Print`，免去够 Print 键） |
| `Super+Alt+P` | 全屏截图 |
| `Super+P` | 屏幕取色（hyprpicker，自动复制 hex） |
| ★ `Super+Shift+R` | 区域录屏 —— 开始 / 停止 |
| ★ `Super+Alt+R` | 全屏录屏 —— 开始 / 停止 |
| `Super+Ctrl+R` | 强制停止录制（保险键，没在录时是空操作） |
| ★ `Super+Shift+O` | **区域取字（OCR）→ 文字直接进剪贴板** |
| ★ `Super+Alt+O` | 全屏取字 |

录屏走 `~/.local/bin/hypr-screenrec`（wl-screenrec 的开关封装）：**同一个键再按一次停止**，
文件落 `~/Videos/screenrec-<时间戳>.mp4`，停止后路径自动进剪贴板，含系统声音。
录制中只有开始/结束两条通知，没有常驻指示。原理与坑见 [05](05-theme-ui.md)。

取字走 `~/.local/bin/ocr-grab` + 一个 systemd socket 激活的常驻识别服务
（RapidOCR，替代 normcap）。框选约 0.33 秒出结果，**每天第一次按会等约 0.8 秒**
（服务空闲 10 分钟自退，那次要重新加载模型），不是卡住了。
按 Esc 取消框选不会有任何通知。原理、调参与坑见 [10](10-ocr.md)。

## 被摘掉的官方键位

`Super+←/→/↑/↓`（方向切焦点）· `Super+S` / `Super+Shift+S`（抽屉）· `Super+Space`（启动器）。

# 终端里（nvim）

`<leader>` = 空格。

| 键 | 动作 |
|---|---|
| `Ctrl+/` | 开/关浮动终端（normal / terminal 模式都能按） |
| `Esc Esc` | 从终端模式回普通模式（kitty 和 toggleterm 都绑了） |
| `<leader>th` / `<leader>tv` | 水平 / 垂直终端 |
| `<leader>tn` / `Ctrl+r` | 给当前终端命名 |
| `<leader>tl` / `Ctrl+f` | 列出并切换终端 |
| `<leader>tt` | 一次开 4 个终端 |
| `<leader>e` / `<leader>E` | mini.files（cwd / 项目根） |
| `<leader>fm` | mini.files（当前文件所在目录） |
| `<leader>z` | no-neck-pain 居中阅读模式 |
| `q` | **已禁用**（防手滑录宏） |

mini.files 窗口内：`l`/`L` 进入 · `h`/`H` 返回 · `=` 或 `Ctrl+s` 同步改动 ·
`gs`/`gv` 分屏打开 · `Esc`/`q` 关闭 · `g?` 帮助。
它是「把目录当 buffer 编辑」——重命名 = 改那一行文字，然后按 `=` 提交。

# ⚠️ 会被合成器吃掉的应用快捷键

Wayland 下全局 bind 直接截获，应用一点收不到：

| 键 | 吃掉了什么 |
|---|---|
| `Ctrl+Alt+L` | JetBrains 系 IDE 的格式化代码 |
| `Ctrl+Alt+H` | JetBrains 的调用层次 |
| `Alt+Enter` | JetBrains 的意图操作；Wine 游戏/模拟器的全屏切换 |
| `Ctrl+1` ~ `Ctrl+4` | 浏览器切到第 1~4 个标签页、VS Code 切编辑器分栏 |
| `Alt+Space` | Wine / 传统 GTK 应用的窗口菜单 |
| `Alt+W` | 带菜单栏应用的「Window」菜单助记键 |
| `Alt+E` | 带菜单栏应用的「Edit」菜单助记键 |

用 JetBrains 系 IDE 的话，把 `mykeys.lua` 里的 `CONTROL + ALT` 批量换成
`SUPER + ALT`（目前只占了一个 `C` 键）。

`Ctrl+W` 被**刻意避开**——它在终端里是「删除前一个单词」，占了得不偿失。

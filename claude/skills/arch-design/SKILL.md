# 架构设计（先画图，后写代码）

和 arch-map 共用同一套地图：**先读 [`../arch-map/FORMAT.md`](../arch-map/FORMAT.md)**。
区别是这里的节点大多是 `:::planned`（紫色虚线框）——设计好了、代码还没写。
代码一步步落地，`planned` 一个个转成带 `@src` 的正式节点，地图最后自然变成 arch-map 能维护的样子。

`docs/arch/DESIGN.md` 是这次设计的**记忆**：决策、待定问题、实现顺序都写在里面。
新会话从它接着做，不要重新讨论已经定了的事——这也是最省 token 的地方。

`DESIGN.md` 的骨架：

```markdown
# 设计：<名字>
## 目标      一两句话：给谁用、解决什么
## 决策      每条：结论 + 为什么（来自讨论或用户的 @note）
## 待定      还没定的问题，以及倾向的答案
## 实现顺序  - [ ] 1. … 每步：把哪些 planned 节点变成真的、要建的文件和接口、怎么验证
```

## 步骤

### 1. 定位

`git rev-parse --show-toplevel` 得项目根。不是 git 仓库就先问用户要不要 `git init`（`@commit` 和锚点都靠它）。

- 有 `DESIGN.md` → **继续**：读它、读所有 `%% @note`，跳到它停下的那一步（还在讨论就去 4，定稿了就去 6）。
- 有 `docs/arch/` 但没有 `DESIGN.md` → **在现有项目上设计新功能**：现有的正式节点不动，新东西画成 `planned`。
- 什么都没有 → **全新项目**：整张地图都是 `planned`。

完成标准：确定了是哪种情况；继续时，知道停在哪一步。

### 2. 讨论

把方案问清楚，直到能画出总览。用 AskUserQuestion，**一次只问一个决策**，每个问题都给出推荐答案和理由。
代码、README、已有地图里能查到的，或者有通行默认值的，不要问——自己定，写进「决策」并注明是默认。

要问清的：给谁用、从哪进来（入口）；3–5 条关键流程；外部依赖和存储；技术栈和硬约束；明确不做什么。

完成标准：总览里的每个框、每条关键流程，都说得出它是什么、为什么需要。

### 3. 画草图

按 FORMAT.md 画：总览、模块图、关键流程。新节点都加 `:::planned`，不写 `@src`。
写好 `DESIGN.md` 的目标、决策、待定（实现顺序先空着）。全新项目还没有提交时，`@commit` 写 `none`。跑 check.py 到退出码 0，再运行 `mmd-view <项目根>/docs/arch/00-overview.mmd`。

然后告诉用户：在查看器里看图，对不满意或想补充的地方，选中节点按 `n` 写备注（不选节点按 `n` 是整张图的备注），
写完回来说一声。

完成标准：check.py 通过，查看器已打开，用户知道怎么留备注。

### 4. 按备注改

用户回来后，读所有 `%% @note`。逐条处理：改图，或者回答并在 `DESIGN.md` 记下决策。
处理完的备注，跟用户确认后从 `.mmd` 里删掉——它已经变成了「决策」里的一条。没处理的保留。
改完重新跑 check.py；查看器会自动刷新，不用重开。

重复 3 → 4，直到用户说定稿。

完成标准：每条备注都有去处——要么变成了图上的改动或决策，要么用户明确说先留着。

### 5. 定实现顺序

在 `DESIGN.md` 的「实现顺序」里拆步骤。第一步是**曳光弹**：打通一条最主要的关键流程的最薄路径，
从入口到存储，每层只做最少的事，先让它跑起来；后面每一步再往上加一块。
每一步写清：把哪些 `planned` 节点变成真的、要建的文件和对外接口、怎么验证（测试或命令）。
每一步要小到一次会话能做完。

完成标准：每个 `planned` 节点都落在某一步里；每一步都有验证方法。

### 6. 实现

问用户现在开始做第几步。做一步就：

1. 写代码，跑这一步写好的验证；
2. 把这一步涉及的节点去掉 `:::planned`，补上 `@src` 锚点（FORMAT.md 的规则）；实际做出来和图上不一样的地方，改图，并在「决策」里记一条；
3. 在 `DESIGN.md` 里勾掉这一步，更新 `00-overview.mmd` 的 `%% @commit`；
4. 跑 check.py 到退出码 0。

一次只做一步，做完停下汇报：做了什么、验证结果、下一步是什么。不要 commit，除非用户要求。

完成标准：这一步的验证通过，check.py 通过，DESIGN.md 已勾选。

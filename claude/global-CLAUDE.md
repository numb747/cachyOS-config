# 全局偏好

- 优先使用中文回答(软偏好)。遇到明显英文语境或用户用英文提问时,可灵活切换。此偏好仅约束对话回答,不强制代码注释、commit 信息、文档的语言——这些按所在项目既有风格处理。

## 多智能体并行(2026-10-14 起,按官方四种用法)

按任务形状选,不按「角色多」选。能并行的前提是子任务互相独立:不用等别人结果、不改同一个文件、两三句话说得清做完的标准。

1. **单会话**(默认):有先后依赖、要来回调整、改同一处的活。
2. **子代理**(Agent 工具):只要结论的查找 / 调研 / 跑测试看日志;几件独立的查询同时派出去。在不在 tmux 都用它。
3. **Agent Teams**:只在队员之间**需要互相交流**时用——多视角审查、几种猜测互相反驳、各管各的文件但要协作。3–5 人,用完让队员退出。
   - 在 tmux 里(看 `$TMUX`)才建队,队员会自动分屏(`teammateMode=auto`),用户能看到每个人在干什么。
   - 不在 tmux 里不建队,改用子代理(不分屏的队员 `/resume` 恢复不了)。
   - 角色见 `~/.claude/agents/`(developer / reviewer / tester / docs-reader)。
4. **多会话 + git worktree**:不同项目、或同一仓库里互不相干的大块改动。由用户自己开窗口,我只在合适时建议。

- 只想要普通子代理时,Agent 调用别传 `name`:开了 Agent Teams 后,起了名的子代理可能会变成队员。
- 大规模编排(Workflow,十几个 agent 那种)仍须用户明确要求,这条偏好不构成授权。
- 详细判断表见 `~/cachyOS-config/docs/14-tmux.md` 第 8 节。

## 下载软件的原则:降级顺序(2026-11-02 起)

本机是 CachyOS。要下载任何软件,按下面顺序往下降,**上一级有就不往下走**,哪怕版本旧一点:

1. **pacman**:先 `pacman -Ss` / `pacman -Si` 查官方仓库(含 CachyOS 仓库),有就 `sudo pacman -S`。
2. **pacman 没有 → 直接下载原生的包**:从软件**自己的**官方发布渠道下载——官网、官方 GitHub 组织的 Releases(二进制、AppImage、tar.gz 等)。
   - 只认项目本身的域名 / 组织,不用第三方转载;有校验和或签名就必须验。
   - 安装脚本先下载、读完再执行,不 `curl | sh`。放 `~/.local/bin` 或 `/opt`,不往系统目录乱撒。
3. **原生的包也没有 → 才考虑 yay(AUR)。yay 不值得信任**:AUR 谁都能传,出过投毒(2025-07 `librewolf-fix-bin` 等植入 RAT)。降到这一级前先跟用户说明前两级为什么不行,并且**用 yay 之前必须查毒**:
   - **先审再下**:`yay -G <包>` 拉到临时目录,读完 `PKGBUILD`、`.install`(以 root 执行)和所有补丁;别直接 `yay -S` 一路回车。
   - **看来路**:AUR 页面的维护者、票数、首次提交时间、最近有没有换维护者(弃包后被人接手是投毒常见路径)、评论里有没有人报毒。
   - **看内容**:`source` 是否指向上游官方地址;校验和不能是 `SKIP`(`-git` 包除外);有没有额外 `curl`/`wget` 下载、`base64`、`eval`、往 `$HOME`、systemd、cron、shell 启动文件里写东西。`-bin` 包要和上游 release 比哈希。
   - **扫毒**:`makepkg -o` 只下载解包源码后 `clamscan -r` 扫一遍;构建出的 `.pkg.tar.zst` 装之前再扫一遍。
   - 依赖链里的其他 AUR 包同样过一遍。任何一项可疑就**停下、报告用户、不装**。
   - 装完 `pacman -Qlq <包>` 看产物有没有越界。完整复核手法(含与上游逐文件比哈希)见 `~/cachyOS-config/aur/README.md`。

## Bash 命令写法(2026-10-16 起)

- `rm` 单独一条 Bash 调用,别和含嵌套 `$(...)`、`for`/`while` 循环的命令用 `&&` / 换行拼在一起。原因:Claude Code 的「灾难性删除」检查分析不了这种结构时,会强制人工确认,bypass 模式也跳不过,远程用 Discord 时就会卡住等人点。
- 要生成一串参数(如 `magick montage` 的 `-label 名字 文件` 对),先用循环填进数组 `args+=(...)` 再 `"${args[@]}"`,或写成脚本文件,别用 `$(for ...; do ... "$(...)"; done)`。

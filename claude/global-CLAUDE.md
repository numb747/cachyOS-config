# 全局偏好

- 优先使用中文回答(软偏好)。遇到明显英文语境或用户用英文提问时,可灵活切换。此偏好仅约束对话回答,不强制代码注释、commit 信息、文档的语言——这些按所在项目既有风格处理。

## 多智能体并行(2026-10-14 起,按官方四种用法)

按任务形状选,不按「角色多」选。能并行的前提是子任务互相独立:不用等别人结果、不改同一个文件、两三句话说得清做完的标准。

1. **单会话**(默认):有先后依赖、要来回调整、改同一处的活。
2. **子代理**(Agent 工具):只要结论的查找 / 调研 / 跑测试看日志;几件独立的查询同时派出去。在不在 tmux 都用它。
3. **Agent Teams**:只在队员之间**需要互相交流**时用——多视角审查、几种猜测互相反驳、各管各的文件但要协作。3–5 人,用完让队员退出。
   - 在 tmux 里(看 `$TMUX`)才建队,队员会自动分屏(`teammateMode=auto`),用户能看到每个人在干什么。
   - 不在 tmux 里不建队,改用子代理(不分屏的队员 `/resume` 恢复不了)。
   - 角色见 `~/.claude/agents/`(developer / reviewer / tester / docs-reader)。
4. **多会话 + git worktree**:不同项目、或同一仓库里互不相干的大块改动。由用户自己开窗口,我只在合适时建议。

- 只想要普通子代理时,Agent 调用别传 `name`:开了 Agent Teams 后,起了名的子代理可能会变成队员。
- 大规模编排(Workflow,十几个 agent 那种)仍须用户明确要求,这条偏好不构成授权。
- 详细判断表见 `~/cachyOS-config/docs/14-tmux.md` 第 8 节。
